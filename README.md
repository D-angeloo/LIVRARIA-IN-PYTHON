# 📚 LIVRARIA-IN-PYTHON

Um sistema de gerenciamento de livraria desenvolvido em Python, focado em lógica de programação, manipulação de estruturas de dados e organização de inventário via terminal.

## 🚀 Tecnologias
- **Python 3**: Linguagem utilizada.
- **Estruturas de Dados**: Uso de listas e dicionários para armazenamento de informações.
- **Controle de Fluxo**: Implementação de condicionais e laços de repetição para navegação no sistema.

## 🛠️ Funcionalidades
- [x] **Cadastro de Livros**: Registro de títulos no sistema.
- [x] **Consulta de Acervo**: Visualização dos livros disponíveis.
- [x] **Gestão de Inventário**: Lógica para controle de entradas e saídas.
- [x] **Interface via CLI**: Interação direta e simplificada através do terminal.

## 📖 Aprendizados
Este projeto foi fundamental para consolidar conceitos de **Lógica de Programação** e entender como os dados são estruturados antes de serem exibidos em uma interface de usuário.
